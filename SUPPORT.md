# Support

If you need help, have a question, want to report a bug, or propose an improvement, please open an issue using one of the provided templates so your request is routed correctly:

- Use the "🤗 Support Question" template for general questions about configuration, adoption, or how defaults behave.
- Use the "🐛 Bug Report" template to report reproducible problems, errors, or unexpected behaviour.
- Use the "💡 Feature Request" template to propose enhancements or changes to defaults or workflows.

Selecting the appropriate template helps provide the information needed to diagnose and act quickly. If your issue falls outside these categories, feel free to open a free-form issue.

If you're unsure which template fits, pick the closest one; issues are triaged and can be relabelled or redirected as needed.
